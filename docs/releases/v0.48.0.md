Works with 0.47 apps and hosts, in either order. On Windows the installer updates the host and its drivers together. A few things need a step from you; see Before you update.

- **Punktfunk hosts on a Mac.** Punktfunk Host is a menu bar app for macOS 15 on Apple silicon: each device gets its own display at its resolution and refresh rate, HDR included, with controllers, pen, the web console and plugins.
- **Streams run at your screen's exact refresh rate.** A TV or monitor at 59.94 Hz gets 59.94, not 60, so the stream no longer drops a frame every few seconds.
- **Your fingers and mouse feel like the host's own.** On a Windows host and a Linux desktop, a touchscreen in Trackpad mode and a Mac or Android touchpad use the host's touchpad settings, and a mouse moves at the host's pointer speed.
- **Play on this device.** The app on the PC that runs your host starts its games on that PC's own screen, with no stream.
- **Two controllers, one player.** A friend's controller can share your player in any game, rumble and light bar included.
- **Give a controller plugged into the PC to a profile,** and every made seat's Steam gets the owner's non-Steam games.
- **IPv6.** Hosts and apps reach each other over IPv6 once you turn it on.
- **Android TV boxes.** Realtek boxes show each picture a refresh sooner, a Chromecast with Google TV and a Xiaomi TV Box S play HEVC without stalls, and PyroWave runs on a Shield TV.

## Before you update

- **Games launched from the library on KDE and GNOME now open in their own gamescope** on a host where nobody chose otherwise. To keep them on your desktop, set **Displays** → **Dedicated game sessions** to **Auto** in the web console. Seats and Game Mode keep their own route, and a host without gamescope launches on the desktop as before.
- **Linux plugins that use the network no longer reach this computer's `localhost`.** A plugin that talks to a server you run beside the host, such as RomM in Docker, asks for that server's port, and you allow it in the web console. For a plugin that doesn't ask yet, type the port into **Allow a port on this computer** on its row under **Plugins** → **Installed**, or run `punktfunk-host plugins grant <plugin> 127.0.0.1:<port>`. See [Let a plugin reach a server on this computer](https://docs.punktfunk.unom.io/docs/plugins#let-a-plugin-reach-a-server-on-this-computer). The packages install `passt` for this; a host diagnostic names it if it is missing.
- **NixOS: log out and back in once** after the update. Until then the host encodes at the default GPU priority.

## New

### Hosts

- **A host on the Mac.** Download `Punktfunk-Host-0.48.0.dmg`, drag **Punktfunk Host** to Applications and open it: a setup window walks you through screen recording, keyboard and mouse, system audio and starting at login. Each session gets a display of its own at the device's mode, in HDR when asked, or streams a monitor. Controllers arrive as a DualSense, DualShock 4, Switch Pro or Xbox Wireless Controller; a stylus as a drawing tablet; touch works as with Sidecar. The menu bar item pairs devices and opens the web console, and plugins run in a sandbox of their own. The microphone, streaming before you log in, and restart and shut-down are not on a Mac host yet. See [macOS host](https://docs.punktfunk.unom.io/docs/macos-host).
- **The exact refresh rate.** A Windows host, KWin from Plasma 6.8, GNOME from 47, sway, Hyprland, niri, Umbriel and a gamescope the host starts run the stream's display at the rate your screen asks for, such as 59.94 Hz. The host tells the app the rate it really runs. Older desktops and Steam's own gamescope session stay at whole hertz.
- **The host's touchpad.** A Windows host gets a virtual Precision Touchpad, and a Linux desktop host a touchpad of its own. Your fingers reach it with the time you touched, so the host OS reads their speed right on Wi-Fi. Pointer speed, scroll direction, tap to click and pinch follow the host's touchpad settings. See [The host's touchpad](https://docs.punktfunk.unom.io/docs/input#the-hosts-touchpad).
- **A Linux host reports your mouse on a mouse of its own,** at the time you moved it. Your desktop's mouse settings apply to it: speed, acceleration, left-handed buttons, natural scrolling. gamescope and a headless session move the pointer one pixel a count, as with a plugged-in mouse. `PUNKTFUNK_MOUSE=0` keeps the old movement. See [Pointer speed](https://docs.punktfunk.unom.io/docs/input#pointer-speed).
- **Play on this device.** A paired app on the host's own PC starts a title on that PC's screen. The web console's Home lists it as **On this PC's screen**, with **End now**, and play time counts for the owner profile. In Steam's Game Mode, the Steam Deck plugin's **Games in Steam** gives each source's games a Steam entry with their own name and art. An emulator started at a Linux desk takes the DualSense, DualShock 4, Switch Pro and Xbox controllers plugged into the box as its players. See [Play on this device](https://docs.punktfunk.unom.io/docs/play-on-this-device).
- **Share a player.** On a session's row in the web console, **Player** offers **Shares Player 1** to **4**: that device's controller joins the player's, buttons combine, and the player's rumble, light bar, player lights and trigger effects reach both. Punktfunk and Moonlight sessions can lead; Punktfunk sessions can share.
- **Controllers on this PC.** The Profiles page lists the controllers plugged into the PC. **Used by** gives one to a profile with a seat: its Steam and games open the real controller, with rumble, gyro, trackpads and its sound. **Rename** tells two of one model apart. See [Give a controller to a profile](https://docs.punktfunk.unom.io/docs/profiles#give-a-controller-plugged-into-the-pc-to-a-profile).
- **The owner's non-Steam games in each seat's Steam,** on Linux and Windows, from the seat's next start. A game's saves land in the seat's own copy, never in the owner's folder.
- **IPv6.** **IPv6** under the host's network settings, off by default, lets devices on your network or a VPN connect over IPv6. A peer from the public internet stays out unless `PUNKTFUNK_IPV6_PUBLIC=1` is set. Seats follow the box.
- **mango.** Each device gets its own headless output in a mango session, captured straight into the GPU encoder. Needs mango 0.17.1 or newer. See [mango](https://docs.punktfunk.unom.io/docs/mango).
- **Switch 2 games through Lichii**, which the host finds and sets up but never installs. Updates and DLC stay where they are, so Eden and Lichii find them.
- **Library launches open in their own gamescope** on KDE and GNOME, at your resolution and rate: the way to stream a game in HDR there.
- **A gamescope the host starts has a performance overlay.** Steam's performance overlay slider drives it; outside Steam, MangoHud's toggle key shows it. It starts hidden.
- **Typed text in gamescope.** A gamescope session types every character your device sends, so a symbol on another layout's Shift level, such as a digit on AZERTY, arrives as typed.
- **Plugins can ask for a server's port** on this computer, and the web console shows which program listens there before you allow it.
- **Lossless surround above 48 kHz.** Such a sound frame no longer fits one packet, so the host sends it in parts instead of switching to Opus. Only 7.1 above 96 kHz still falls back.

### Apps

- **Play on this device.** The Linux and Windows apps, the controller interface and the `punktfunk` command mark the host on their own PC as **This device**. Its library starts games on that screen, and the app steps aside, controllers included, until the game ends.
- **Native asks for your screen's exact rate** on Android, the Mac, Windows and Linux, and in the console. The option names it, such as **Native (59.94 Hz)**. Android measures what the panel really runs, as a tablet that states 60 Hz may refresh at 59.88.
- **Fingers to the host's touchpad.** A touchscreen in **Trackpad** mode on Android, iPhone, iPad, Windows and Linux, a Mac's trackpad and an Android touchpad with the mouse captured send their fingers; an iPad trackpad sends its pinch. With **Invert scroll direction** on, fingers scroll the way they did.
- **A captured mouse sends its own counts** from Android, iPhone, iPad, the Mac, Windows and Linux.
- **Steam Deck: Steam's on-screen keyboard** types the characters it shows, also on a host with another layout such as AZERTY.
- **Keep this address.** A host's page and the console's host menu pin a host to the address you saved: a host on a direct link beside your home network no longer moves to the slower one when the direct one misses a reply.
- **IPv6 hosts.** Every app dials a host's IPv6 address, typed with or without brackets.
- **Stream in background** can keep a session for 60 minutes under **Disconnect after**.
- **Lossless audio** offers every rate at every channel count on Windows, Linux and the console.
- **Android: HDR on a screen that reports no HDR headroom.** The switch starts off and asks once, since the picture may look darker than SDR. The console asks the same.
- **Apple: a pad's extra buttons** reach the host's grips: a Razer Kishi's L4 and R4, an Xbox Elite's paddles.
- **Windows app on winget:** `winget install unom.PunktfunkClient`.
- **Apple TV:** each release carries an unsigned app to sideload with your own Apple ID.

## Improved

### Hosts

- **Loss recovery.** A link that drops out for longer than eight frames still heals from the last picture both ends hold, instead of a wave or a keyframe. A device whose decoder can't heal by waves gets a keyframe at once.
- **Intel.** HEVC encodes through VAAPI at about half the time Vulkan took, with intra refresh after a loss. Tiger Lake and Rocket Lake without HuC firmware encode at half the render load.
- **HDR in gamescope** reaches the encoder without a conversion pass.
- **Input under a busy CPU on Linux.** The threads between the network and the injector run above the game, and a launched game starts at normal priority.
- **Faster starts.** A reconnect or resume reaches its stream a second sooner, a seat wakes up to a second sooner, the next game starts as soon as the last one closes, short launch steps no longer cost 100 ms each, and the Linux and Windows apps dial while their overlay still loads. On NVIDIA the first stream after a host start sets up capture alongside the display.
- **HDR follows the game on a shared-screen host.** A gamescope session alone on its screen switches between HDR and SDR with the game, also where devices may join it.
- **Moonlight.** Input and repair requests are handled as they arrive, and its audio no longer clicks under a busy CPU or drifts behind on a fast capture clock.
- **Audio in Monitor mode** follows the capture clock, so a hardware sink that drifts no longer puts short silences between real sound. 7.1 at 48 kHz stays lossless from the first second of a connection.
- **Motion after a pause** no longer lags for a second on the Windows, Linux and Android apps.

### Apps

- **A tapped button survives a lost packet.** Every app sends a button change three times within 16 ms, so a lost press no longer waits 100 ms or vanishes, and a lost key arrives about 25 ms sooner.
- **Android: Realtek boxes** show each picture a refresh sooner, later sessions in the same app run start that way, and automatic bitrate climbs on them.
- **PyroWave on more Android devices:** Vulkan 1.1 devices such as the Shield TV, and 32-bit devices such as the Chromecast with Google TV 4K.
- **Android 9 to 12** show frames on time: Android 10 to 12 no longer drop one in ten at the panel's rate, and Android 9 and 10 forward a finger about 8 ms sooner. Under **Lowest latency** a frame no longer waits a refresh behind the one before.
- **Android connects faster:** it reads the decoder list once per connect. **Send logs to host** now names each forwarded controller and every decoder the device has.
- **The stats overlay** costs far less on an integrated GPU at 4K, and the console keeps its covers cached at 4K.

## Fixed

### Hosts

- **Steam's Game Mode** no longer goes to sleep during a stream under **Sleep after**.
- **GNOME.** The host sees a launched game's window and its exit.
- **Intel.** With gamescope, an Arc B580 no longer streams columns of noise, a 1080-line picture no longer shows its colour 16 lines too high, 10-bit no longer repeats the picture across, and Tiger Lake and Rocket Lake no longer drift into a purple smear.

- **A Proton game above 96 DPI** in its own gamescope no longer shows a green rectangle.

- **A box another user or the login screen holds** no longer goes to sleep during a stream.

- **Controller bindings.** One game's exit no longer resets the bindings of a game that is still running.
- **Windows.**

  - A burst of mouse moves on a busy link no longer throws the pointer further than the mouse moved.

- **PyroWave on Automatic** follows the picture the host really encodes when it differs from what the app asked.
- **Plugins.** The runner starts on a fresh Arch install and on the Steam Deck, so the library has its games. An uninstalled plugin leaves the console at once.
- **Setup** no longer stops at its first step when started with `ujust` on Bazzite. A host update run from the web console no longer stops at a config-file question on Debian and Ubuntu.
- **SteamOS.** A host update no longer reads as failed after the host restarts.
- **Seats.** Reachable without logging in says whom it is on for before you try to switch it. On SteamOS, turning it on no longer opens the console to your whole network when you kept it to this machine.

## Security

- **Plugins.** A Linux plugin with network access runs in a network of its own, and gets only the ports you allowed on this computer. A Mac plugin runs in a Seatbelt sandbox with the same rules. No grant binds `/tmp` or a desktop's sockets. A folder request shows the real folder Allow grants, and saving a plugin's form grants only the folders you confirmed. A store install runs only the bytes the catalog checked. A Windows plugin outside its container reaches the host over pinned TLS.
- **The web console** never runs a seat host's answer as a page, and one person opening consoles can no longer end everyone else's. A used sign-in ticket can't be spelt another way and used again.
- **Pairing.** A sandboxed or cut-off page origin never counts as one you approved, and pending requests can no longer hold connections past their limit.
- **Profiles.** A Moonlight client sending input fast can no longer keep playing on a profile you just locked, and a View only device can no longer start another account's seat by dialing it.
- **Network.** A slow or idle peer can no longer hold the host's management slots, tunnel streams, control stream or seat calls, and a compressed answer can no longer fill memory once unpacked. One Moonlight control peer holds at most 1 MiB. Over IPv6, a public peer counts as one for its whole /64 network.
- **Windows host.** It opens only local-disk paths that the registry names, loads Intel's runtime only from system folders, and hands an emulator only files it holds, through links no one can swap. Players can no longer write where the host keeps an emulator's manifests. An install folder another account touched stays untrusted. A pasted image, a stuck capture worker or a pad driver request can no longer exhaust it.
- **Mac host.** A copy a password manager marks as concealed stays off the shared clipboard.
- **Input.** A device with only the controller grant can no longer type or move the pointer through a Steam Controller 2, or a PlayStation pad's touchpad. A touchpad or pen reaches a host only where the host offered one.
- **Seats.** A controller that changes hands cuts every open handle at once. Switching Reachable without logging in to another member leaves none of the last owner's pairings or password.
- **Apps.** A host can read only clipboard formats you offered, and can no longer crash an app with a malformed stream, a PyroWave packet or a long chunk header, fill its memory while it connects, or send a held-back command to a Bluetooth controller. The command line and the Linux app show host text as plain text. The Linux client Flatpak reads only its own legacy files. Android's library downloads refuse eight compromised certificate authorities.
- **Linux packaging.** On NixOS only the host's users run the GPU-priority encoder. Setup trusts the console's certificate for the console alone; running setup again replaces an older entry. The Bazzite feed signs only lines it verified. `ufw allow punktfunk-gamestream` opens the three UDP ports the host uses; an existing rule narrows after `sudo ufw app update punktfunk-gamestream`.
- **Moonlight pairing** signs with a constant-time RSA key.
- **Dependencies** with published advisories are updated: zlib in the Windows seat keeper, the URL parser in the host and the seat keeper, and the web console's and docs site's build packages.
