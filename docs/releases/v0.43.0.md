Wire-compatible with 0.42.0: a new client streams from an old host and the other way round, so you can update one side at a time. On Windows the installer updates the host and its drivers together.

- **Hosts install games when you start them.** A library plugin can list games the host does not have yet. Start one and the host downloads it, with progress on the launch screen; pause, cancel or remove it from any client or the web console.
- **A network check says what your link does,** in words, and offers paced delivery for that host in one press.
- **Samsung TV, in preview.** The browser client runs as a sideloaded app on Samsung TVs from 2024 on.
- **Android dual screens do more.** One picture can span both screens, and DS, 3DS and Wii U games start that way. The companion panel gains a keyboard and live graphs.
- **Real 10-bit SDR** from Windows 11 24H2 hosts and gamescope sessions. Other hosts stream 8-bit SDR unless they allow widening; see Before you update.
- **gamescope 3.16.31.** Proton games draw again in dedicated sessions, non-Steam games no longer hide behind the Steam splash, and Flatpak games open inside the session.
- **Controller rumble can be turned off** on the client.
- **punktfunk/2, in preview,** on hosts that turn it on: video rides the connection's own port, so one port forward is enough.

## Before you update

- **10-bit SDR needs the host's yes.** A client set to 10-bit SDR now gets 8-bit unless the host turns on Host → Settings → Video → Allow 10-bit SDR (advanced). A desktop delivers 8 bits of SDR, so widening only cost encoder time. Windows 11 24H2 hosts and gamescope sessions capture real 10-bit and need no switch. HDR is unchanged.
- **Some hosts make a new identity, and their apps pair again once.** A host that still showed apps its old RSA certificate creates a modern one on first start and warns in its log if apps were paired. Moonlight pairing is unaffected.
- **NixOS:** the host, the client and the patched gamescope build against your system's nixpkgs, so AMD and Intel load EGL, Vulkan and VA-API on nixos-unstable. Each update compiles them unless your flake sets `inputs.nixpkgs.follows = "punktfunk/nixpkgs"`.

## New

### Library downloads

- **Games the host does not have yet** show their size on the tile and an Install row in the title menu, on the console, Android, Apple and the web console. ROM Manager 0.11.0 lists RomM titles this way.
- **Starting one downloads it.** The launch screen shows bytes, speed and time left, and the game starts when the files are complete. A stopped download ends the wait with its own message.
- **Pause, cancel and remove** from the title menu or the web console's library, which can filter to games on the host or not yet. Removing and cancelling ask first.
- **A Manage downloads access level** lets a device pause and remove titles without full control of the host. Full control includes it.
- **A Windows host stays awake while a title downloads.** The display may still sleep.

### Network check

- **The speed test finds the link's ceiling first,** then measures loss and jitter in a clean round at half of it, instead of reporting the loss of its own flood. Every client shows both figures.
- **The network check** adds shaped rounds and says what it found: a host port faster than this device's, loss at the head of a burst, a receive buffer too small, a cable, port or duplex fault, a path that buffers, or Wi-Fi. It names the delivery profile that helps. It is on every client's speed page, and in the host card's menu as Check network.
- **Paced delivery, per host.** One press in the results stores Capped or Smooth for that host, and the next session asks for it. A host with nothing stored streams as before.

### Samsung TV

- **A Samsung TV app, in preview,** for sets from 2024 on (Tizen 8.0). It is the browser client in console mode for the remote, and it is sideloaded: the Samsung TV guide covers Developer Mode and the install. Back at the start screen exits the app.
- **A host with Browser origins set admits the TV app,** which sends no origin. Pairing still decides who streams.

### Android

- **Spanned layout.** One picture spans both screens of a dual-screen handheld, and DS, 3DS and Wii U games from the library start spanned. Swap screens becomes **Screens** and steps through every layout; the picture moves between screens without a decoder restart.
- **The companion panel is rebuilt** with a side rail and Session, Host and Leave headers. Its stats open on sixty-second graphs of frame rate, latency, bitrate and loss, and a **Keyboard** page sends keys with latching modifiers, as a physical keyboard would. A USB-C display that reports no size counts as the panel.
- **Second screen** setting, on by default: a preset can turn it off, so a handheld on a TV keeps the stream on one screen.

### Apple

- **An iPad keyboard opens the quick-action dial** with the same chord as the Mac.

### Every client

- **Controller rumble** setting under Controllers, on by default. Off drops the host's rumble at the client and silences the console's own menu buzzes. The browser and webOS clients do not have it yet.
- **Stream controls** in About lists every key, chord and gesture, on the console and on Android.

### Linux hosts

- **Hyprland and wlroots capture HDR monitors directly** in 10-bit with their HDR metadata, and a Hyprland virtual display lights up in HDR for an HDR session.
- **Text clipboard in gamescope sessions,** including dedicated sessions, which used to bind the desktop's clipboard.
- **Punktfunk Host in the app menu** starts the host, the web console and the plugin runner, then shows the tray. The tray lists each of the three with its state and Start, Stop and Restart.
- **Intel Arc can offer AV1** through Vulkan Video encode on Mesa 26.2 or later.

### Windows hosts

- **Real 10-bit SDR** on Windows 11 24H2 from a wide-colour display, on NVIDIA, AMD, Intel and PyroWave, with no widening switch.
- **Punktfunk Host in the Start menu,** for every user, starts a stopped host behind one UAC prompt.

### Linux and Windows clients

- **A DualSense over Bluetooth plays the game's speaker sound and voice-coil haptics,** carried in the controller's own reports. It used to fall back to rumble.

### Linux client

- **Hyprland runs variable refresh for the stream, and KWin tells a TV to use game mode:** the window is tagged as game content.
- **Pacing reads the real on-screen time** from the driver on Mesa 26.1 and newer and on NVIDIA, and from the compositor on older Mesa, so variable refresh is detected there too. The stats line names the compositor's path: scanout, composited or a screen share.

### punktfunk/2

- **A preview of the next protocol,** off by default. A host turns it on with `PUNKTFUNK_PROTOCOL=2`, and 0.43 clients follow without a setting. Video and audio ride the connection's own UDP port, so firewall rules for the listen port and one WAN forward are enough, and a client that changes networks keeps its video. A device waiting for approval hears that it waits, a host clock step no longer costs a recovery frame, and clipboard sharing works. Browsers and the Samsung TV app use it too where it is on.

## Improved

- **Windows hosts send each frame as it lands** instead of on a fixed tick, removing up to a frame of delay that changed from session to session.
- **A game well below the stream's rate** no longer waits behind repeated frames: 60 fps in a 120 Hz stream lost up to 6.7 ms.
- **AMD Windows hosts encode HDR straight from the composed surface,** taking a shader pass and a copy off the GPU a game renders on, and no longer reserve 200–400 MB of copy textures at 4K, which matters on integrated GPUs.
- **Intel Windows hosts read frames in place,** removing a copy per frame.
- **NVIDIA hosts take gamescope's NV12 and P010 directly,** so SDR and HDR skip the colour conversion on the game's CUDA cores, and gamescope composes those formats in GPU memory.
- **Hyprland and wlroots hosts hand NVIDIA one conversion pass** instead of three or four copies.
- **Linux encodes keep fewer buffers locked,** so a game's next frame no longer waits behind the encode.
- **A burst that loses the head of a frame costs one frame instead of two,** and a still desktop no longer freezes for up to 3 s after a loss.
- **Automatic bitrate climbs after a lost first capacity test** instead of holding the starting rate all session.
- **Reconnects and takeovers wait only until the old session lets go,** not a fixed 1.5 s.
- **Shortcuts screens list everything** on the Mac, iPad, Windows and Linux clients: mouse mode, clipboard, release chord, controller and touch.
- **The controller test and the web console's Controllers page draw your pad itself,** so a Deck, a Joy-Con pair or a GameCube pad no longer shows as another pad.
- **The Default gamepad row lists all 18 pads the host builds,** so a Joy-Con pair, 8BitDo, HORI or Switch Pro pad no longer falls back to an Xbox 360 pad.
- **Linux packages bring punktfunk's gamescope:** Arch requires it, and the deb and RPM packages recommend it (not on Ubuntu 24.04), so HDR and the cursor in gamescope work without a manual install.

## Security

- **The Windows installer adopts an existing host.env or console password file only when Administrators own it,** and new secret files are created unshared.
- **A paired device's status hides other devices'** names, addresses and fingerprints.
- **Covers are served only from real image files,** so a linked cover can no longer read a secret.
- **A plugin install rolls back** unless its lockfile matches the catalog's pin, and a revoked plugin token stops working at once.
- **End game stops only processes in your own session.**
- **Peers that stall during the handshake** can no longer fill the host's session slots, on the app and browser planes.
- **Deep links whose game id starts with a dash** are refused on every client.
- **Apps always get the host's P-256 identity.** The RSA certificate is GameStream's alone.
