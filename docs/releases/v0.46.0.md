Works with 0.45 hosts and apps, in either order. On Windows the installer updates the host and its drivers together. Three things need a step from you; see Before you update.

- **Snapdragon devices show true blacks and whites.** The Logitech G Cloud and other Snapdragon devices on an older vendor image showed every SDR stream with crushed blacks and clipped highlights. The host now sends them the colour range their display expects, for HDR too.
- **AMD RX 9000 Windows hosts no longer look washed out.** Those cards write a limited range whatever they are asked, so the host tests the GPU once and labels the picture to match. AV1 from any AMD Windows host carries the right range too.
- **Bitrate → Fixed holds your PyroWave quality for the whole session.** Fixed was Automatic in disguise: the rate still moved mid-stream.
- **Automatic bitrate stops cutting on a clean link.** A host's encode time, a Wi-Fi path's fixed delay, a clock step and an Apple TV's own keyframe asks no longer read as a failing link. A Steam Deck that opened under 5 Mbit/s and a 1 GbE session held at 20 Mbit/s now climb.
- **Umbriel is a host desktop.** The Noctalia project's compositor makes its own virtual outputs, so each device gets one, captured straight into the GPU encoder.
- **Seats play the box's emulators,** each with its own saves. A Windows seat can be one of the PC's own accounts, SteamOS and Windows seats stream HDR, and the box stays awake while anyone plays on a seat.
- **Bazzite hosts come back after a reboot,** Return to Gaming Mode works after Switch to Desktop mid-stream, and the switch no longer ends the stream.
- **Profile pictures show on every client,** and Apple TV streams real HDR: every Apple TV tone-mapped HDR into SDR.

## Before you update

- **SteamOS and Bazzite with Reachable without logging in: update once from Konsole.** Run `bash ~/punktfunk/scripts/steamdeck/update.sh --pull` and enter your password. The console update moved only your own host and left the login-free copy, and its seats, on the old build while saying Updated. From this version on the console says so and the update asks for the password.
- **Attach mode is gone from Host → Game Mode.** To keep streaming the screen the box drives, pick it under **Displays** → **Stream this monitor**, or set `PUNKTFUNK_GAMESCOPE_ATTACH=1` in `host.env`. A Bazzite or SteamOS box that had the row on now takes Game Mode over for the stream unless a screen is pinned.
- **Windows app: Windows App Runtime 2.6.4 or newer.** The installer and the Store package bring it; a portable copy asks for it at start.
- **PyroWave with a bitrate you set for another codec:** that number now counts as Fixed, so you stream at full PyroWave quality until you set **Bitrate** back to **Automatic**.
- **Linux, a hand-written door unit:** `PUNKTFUNK_DOOR=1` no longer makes a host the door; pass `serve --door`.

## New

### Hosts

- **Umbriel.** Each device gets a virtual output of its own at its size and refresh rate, keyboard and mouse go in through the wlroots protocols, launches open on the streamed output's workspace, and **Turn off** darkens your monitors over Umbriel's IPC. It needs an Umbriel built on 2026-09-28 or later and a GPU encoder: Umbriel has no screen cast, so there is no software path. See [Umbriel](https://docs.punktfunk.unom.io/docs/umbriel).
- **Seats play ROM Manager titles.** On a box with seats the emulators install for every account, and each seat keeps its own config and saves. A Linux seat sees the folders you granted the ROM Manager plugin, read-only, and its saves travel through your plugins. RPCS3, shadPS4, Supermodel, Vita3K and Xenia Canary stay on the owner's desktop on Linux; on Windows RPCS3, Snes9x and Supermodel keep one set of saves for everyone. An emulator installed while seats were off keeps one set until you reinstall it under **Library** → **Sources** → **Emulators**.
- **Windows: a seat on an existing account.** Under **Add profile** → **Own desktop**, pick **Existing account**, the account and its Windows password. Sign the account out first; an administrator can't be a seat. While it is a seat, nobody signs in to that account at the PC. When its password changes, the card says so and **Update password…** takes the new one. **Remove** gives the account back with its files.
- **Windows: hooks and prep steps as administrator.** Tick **Run as administrator** on a hook, after running `punktfunk-host hooks elevated on` once from an administrator PowerShell. There is no UAC prompt, and Windows commands now get the `PF_*` variables, such as `PF_STREAM_HDR`. On Linux the guide gives a sudoers recipe.
- **Windows: Your monitors while streaming per device.** The device's **Display settings…** sheet offers it, as on Linux. The first device to connect decides it for every device that joins.
- **Studio-range streams.** Every encoder on Linux and Windows hosts sends SDR or HDR at limited range when a device asks for it, and Moonlight gets the range it names, so an LG TV on moonlight-tv no longer clips blacks and highlights. PyroWave stays full range.
- **Encoder → Vulkan works on NVIDIA.** Vulkan Video encode never opened on an NVIDIA GPU before.
- **NetBird counts as your local network.** A device on NetBird's `wt0` pairs with **Approve** and reaches the console, like one on Tailscale. Omarchy's firewall setup opens the ports there too.
- **Reachable without logging in takes directory accounts.** An owner named `user@domain` from Active Directory or FreeIPA, and accounts with a uid above 65535, work on Linux.
- **Stop hands Game Mode back.** Stopping a gamescope stream from the app or the console hands the box back after a moment instead of waiting out the keep-alive with a dark TV. **Keep until released** still wins, and a keep-alive window counts the time the box slept.

### Apps

- **Profile pictures.** The picker, the host card's badge and the console's Games pill show each profile's picture on Windows, Linux, Mac, iPhone, iPad, Apple TV, Android and the Decky panel.
- **Linux: stream from several hosts at once,** each in its own window. Connect to the next host from the same app; a controller follows the window you're in, and the banner offers **Disconnect All**.
- **Browser: streams on networks that block UDP.** When the page can't reach the host over UDP it switches within seconds to a WebSocket path through the machine that runs the page. It adds latency and stutters more under loss, and it is a preview.
- **The Windows installer follows your Windows accent colour,** logo included, and repaints when you change it.
- **iPhone, iPad, Apple TV, Mac and Android dial a woken host again.** The first connect after Wake-on-LAN no longer fails while the host's display and GPU come back.
- **Switch 2 pads reach the host as themselves.** Switch 2 Pro, GameCube and Joy-Con 2 pads, C button included, on every client. Switchroot's Joy-Cons stream as a pair.
- **Android: the host's pointer rides on your mouse in Desktop mouse mode,** at input rate instead of the stream's latency. Touch, a remote or a pad hand the pointer back to the host picture.
- **Video codec sits beside Bitrate and Prioritize** on every client, without Show advanced. PyroWave quality moves with it.
- **PS5: the HDR row,** so a stream to an HDR display can stay SDR.
- **The Stream controls page lists the webOS remote's held Yellow,** which opens the quick-actions dial on a TV with no pad.

## Improved

### Hosts

- **Linux virtual displays, about ninety fixes.** Under keep-alive a device gets its own desktop back, and a second device at the same size no longer takes the first one's windows. On Hyprland and niri a device's head keeps one name across connects, so workspace binds, placement and scale follow it. A host killed mid-stream no longer leaves the desk dark or other apps' screen share broken, and a reboot puts the screen-share picker back. GNOME keeps an HDR panel's mode, a TV's underscan and a mirrored pair during a stream. KDE no longer drops crash reports on the desktop after a reboot, matches outputs by exact name, and never takes a monitor plugged in mid-connect for the stream's. Resuming a running game after a reconnect brings its workspace onto the new screen on Hyprland, sway and niri. A console save that changes one display setting keeps the others.
- **Windows virtual display driver.** A device that joined another's stream keeps it when the owner reconnects. Monitors that leave together are regrouped once, so the streams that stay bounce less. Ghost monitors go without PowerShell, which cost the first connect after a host start several seconds. A replaced cursor no longer blends its old shape at its old spot, and a failed encoder reset no longer leaks until reboot. The console's display list refreshes on every change, and a host restart no longer blanks a live seat's desktop.
- **SteamOS, Bazzite and gamescope.** A Switch to Desktop mid-stream keeps the stream, brings the desktop's own Steam back and no longer reads as the game quitting; Return to Gaming Mode no longer stalls for a minute. A 4K120 TV mirrored into the stream paces at 120, not 60. A gamescope that dies on start fails the connect at once instead of after 30 or 45 seconds, and a second device connecting during a launch no longer kills the first one's session. HDR, the in-node cursor and custom refresh rates no longer vanish for the host's life after a slow boot. A title launched on a desktop box pinned to gamescope reaches the stream, and a bare session's test cube no longer opens on the desktop. Steam shortcuts made by the Decky plugin run again when Steam forces a compatibility tool on them, and the plugin finds gamescope's socket on Armada OS.
- **Reachable without logging in, on Linux.** The door keeps its name, discovery and seat settings across a switch, the console stays signed in through it, and a switch that fails says so at once instead of after two minutes. Turning it off no longer answers that the host has no owner, which every Linux box did since 0.44. The DualSense switch reaches the seats, each session is listed once, and a dead seat's gamescope is cleaned up. SteamOS seats get the HDR gamescope, a seat's first launch no longer sits dark for two minutes, and plugins on a seat start. The door and the seats start after a reboot on every system-extension install.
- **Windows seats.** HDR holds on a seat. Seats on PCs that lose their display paths come back without an 18-second wait, and a guest who reconnects often is no longer signed out at the eleventh drop. A seat's emulator settings no longer undo another seat's mid-game.
- **Automatic bitrate.** A fixed H.264, HEVC or AV1 rate now measures the link too, so a slower hop no longer kills every frame; frames that die unseen count as loss, and parity holds while they do. A console decoding 4K120 no longer sheds its queue every two seconds. The low-rate warning names what drove the rate there: the decoder, the host's encoder or the link. Delay is read from the host's send, not its capture, so a contended GPU no longer reads as a queue. The stats overlay's network figure no longer climbs from 1.5 to 13 ms and snaps back.
- **PyroWave.** Intel Arc Windows hosts stream it. 4K frames with an odd packet size no longer freeze the picture while audio plays, and a speed test no longer pins the decoder. **Encoder** → **PyroWave** now applies to devices on an automatic codec that can decode it; an HEVC or AV1 device gets the normal encoder instead of frames it can't decode.
- **Plugins.** A Steam folder with inheritance cut showed 0 games and no prompt, and the cure rewrote every game file below it; the host now asks for the folder's own files and lands at once on a tree of any size. Windows launchers are read from the registry in process, so a blocked `reg.exe` or a non-ASCII install path no longer empties Ubisoft or GOG. A library whose game folders each hold one small file is granted with one yes, and a Steam root whose `steamapps` is a junction no longer reads 0 entries. A plugin that lost its folder permission no longer crash-loops until a restart.
- **Moonlight.** A KDE host whose launches open a dedicated gamescope offers HDR. A launch follows the host's policy toward native streams. Taking a grant away mid-press releases the key, button or stick on the host.
- **Umbriel speaks both IPC shapes,** so a newer Umbriel build no longer leaves the stream black.
- **KDE: an iPad's pointer no longer snaps to the centre** in the first second of a stream.
- **A Deck's door console says when its seat copy is behind,** instead of Up to date.

### Apps

- **Apple TV.** HDR passes through to the display instead of being tone-mapped into SDR, at less GPU. A 1440p stream on a 4K Apple TV no longer runs at 30 fps. When tvOS re-plumbs the display mid-session the picture comes back in about five seconds instead of staying frozen until you leave the app.
- **iPhone and iPad show each frame a few milliseconds sooner** at 120 Hz with HDR, and an iPad on Display Zoom's More Space draws 1:1 again.
- **Mac.** A captured mouse sends its own counts, so a Windows host no longer accelerates an already accelerated pointer. Native on a notched Mac sizes to the menu-bar band, so the picture snaps 1:1 again.
- **Vision Pro.** No shimmer at the screen's edges. A controller press no longer pinches whatever you look at while streaming. The curve's controls rest as the window's do, and the ring's Keyboard slot opens the keyboard on the curve.
- **iPhone, iPad and Apple TV console: pairing an advertised host works** instead of ending in "That host is no longer saved".
- **Android TV and the Shield.** Frames are paced on the compositor's clock, so a display that holds frames no longer costs a drop and a repeat dozens of times a minute. Lowest latency no longer flips between refreshes for a minute at a time, and a 60 fps source on a 120 Hz panel keeps an even beat.
- **Android.** AV1 HDR from a Windows host no longer shows grey and dim on a Pixel 7. Tablets that held 60 Hz run at 120 again, and the app is back in the TV launcher's Games row. A 1080p AV1 stream from an AMD host no longer shows a strip under the picture. A decoder that failed a call no longer starves until the picture froze.
- **Windows app.** Settings scroll again after switching sections, and the hosts page no longer paints every status red. A link that launched the app opens the right screen, and a bad link during a wake or a stream no longer drops you to the host list.
- **Windows and Linux apps.** Alt+F4 reaches the host while **Capture system shortcuts** is on. The pointer no longer jumps back when a host hides and shows it. A link's preset and profile survive pairing. The Linux app started by gamescope shows HDR and opens inside gamescope, and a title launched by Steam on Armada OS decodes on the GPU again. The console window has its own app id, so a pinned Punktfunk Console launcher matches its window.
- **Every app follows a host's new name** on its saved card, unless you typed the name yourself.
- **The exit chord no longer presses Guide first.** Holding Select, then L1, R1 and Start ends the stream without opening the Game Bar or Steam's overlay on the host.
- **Console.** A mouse, Magic Remote pointer or finger reaches the host cards. Holding B leaves the controller test with a pad that sends nothing while held. TVs without a clipboard no longer show the clipboard row. On webOS, Host and profile no longer waits forever for profiles.
- **Web console.** The Devices page keeps the list that loaded when the other fails and says when an unpair was refused. A host update seen after a page reload times out instead of showing progress forever. A seat's log lines stay between polls.
- **Command line.** `network-check` says when it measured no loss instead of "Nothing to fix". `hosts add` fails when it couldn't save, and its help says a second fingerprint at an address is a second host.
- **Report a problem** in the apps and the docs now leads to Discord's `bug-reports` forum or the form on the community page. The old link ended at a tracker nobody could sign up for.

## Security

- `pair --request-access --fp` with the fingerprint missing no longer falls back to an unpinned pairing; it exits with an error, as `hosts add --fp` does.
- A Moonlight session whose keyboard, pointer or pad grant is withdrawn releases what it still held.
- On a Linux box reachable without logging in, the tray's token is no longer written where seat accounts can read it, and a removed seat's copy of the box's pairings goes with the account.
