Wire-compatible with 0.39.0: a new client streams from an old host and the other way round, so you can update one side at a time. On Windows the installer updates the host and its drivers together.

- **The console is rebuilt for the remote.** Hosts, Games, Controllers and Settings are tabs that four directions and OK reach, Games reads like the Mac library and searches, and presets are made from the couch. It is the controller interface on every client, Apple's included.
- **The pointer is where it should be.** One pointer, with the right shape and size, on every host — after a Windows UAC prompt, across monitors and for a player who joins.
- **Audio lines up with the picture.** Sync counts the speaker's own delay, Bluetooth included, and Windows playback and the Android mic come back when a headset connects or drops.
- **HDR holds on more setups.** A Windows HDR session on an SDR display no longer freezes black, Moonlight HDR on gamescope is real HDR, and 10-bit SDR stays 10-bit to the screen.
- **KDE and AMD hosts keep their frame rate.** KDE capture stops rebuilding its screen, and an AMD encoder no longer freezes the picture after a scene cut.
- **PyroWave reaches the screen sooner**, and its quality is one setting in bits per pixel.
- **Windows controllers act like the real thing.** An Xbox pad shows up once in Steam, SDL games read the Steam Deck pad, and two pads never merge into one.
- **Plugins recover from the sandbox move.** Saved settings come back, ROM folders on an SD card can be granted, and ROM Manager and itch fill their libraries on Windows.

## Before you update

- **The Mac app needs Apple silicon.** An Intel Mac keeps the version it already has.
- **Only Tailscale counts as local in the 100.64.0.0/10 range.** A peer there passes the console's local-network check and pairs as local only when the host reaches it over Tailscale. Other VPNs that hand out those addresses, such as NetBird, now count as the internet on Linux and Windows hosts.
- **Turning the plugin sandbox off moved.** `PUNKTFUNK_PLUGIN_SANDBOX=off` in host.env never reached the plugin runner. Set it with `systemctl --user edit punktfunk-scripting` instead.
- **Windows: update the host with its installer.** It replaces the controller drivers and checks that no old build is left. If Steam still lists one controller twice, restart the host PC once.

## New

### The console

- **Four tabs.** Hosts, Games, Controllers and Settings. Up past a screen's first row reaches the tabs, and L1/R1 or Tab jump from anywhere. Back at a tab's root leaves the console.
- **Hosts is the home.** Down from a host's card reaches its actions — Games, Connect with, Wake, Details, More — and Down again reaches that host's games. Host order and Group hosts by sort and band the row as the Apple home does.
- **Games follows the Mac library.** Host chips and Customize on top, then Desktops, Recently played, Favorites, Launchers and the Games grid, in the order you set. Customize works with a remote alone. The grid can switch to a cover-flow Shelf, and Search finds a title by name.
- **A title's menu and card.** Holding OK, or Y on a pad, opens Play with preset, Favorites, Details and Copy link. Details shows the cover, the store, platform, developer, year, genres and a play line such as "Last played 2 h ago · 14 h total · 12 launches".
- **Settings in sections.** Stream, Picture, Sound, Controllers, Input, Interface, Presets and About. Keep streaming in background, its timeout and the stats corner join them, and the open-source licences draw in the console itself.
- **Presets from the couch.** New preset, Edit settings, Rename, Pin to hosts and Delete, with a dot on every row the preset overrides.
- **Host details in section tabs,** with Unpair beside Remove: the host keeps its name, address and presets and asks for a PIN on the next connect.
- **Controllers tab.** Each pad is a card with its family's outline, what it streams as and its battery. A Test card lights every button, tilts the sticks and fills the triggers, and lists the other input devices.
- **Pick a background by looking.** Thirty-six palettes as cards, applied at once. The default is a brighter, slowly moving gradient, drawn in 10 bits where the screen has them. On Linux and Windows the console follows the desktop's reduce-motion setting.
- **The speed test draws a live graph** of the link as it measures, then marks the recommendation on it.
- **Touch follows the finger.** Lists and the Games grid track a drag and keep moving after a flick, and a finger held still for half a second opens a row's menu.
- **A TV gets only the rows it can use** — no phone rumble, gyro or Copy link.

### Apple

- **The console is the controller interface on iPhone, iPad, Mac and Apple TV.** A pairing request, a link to open and an error all answer inside it, so a pad reaches everything.
- **Apple TV's remote drives the console fully.** Clicks, a held direction that repeats, swipes on the clickpad, and the system keyboard — so a field can be typed from an iPhone or by dictation.
- **A Bluetooth mouse and keyboard on Apple TV reach the host.**
- **Mac: capturing system shortcuts no longer asks for Accessibility.** ⌘Tab, ⌘Space and Mission Control reach the host while captured, and a hung app still lets Force Quit through.
- **Late-latched frames on iPhone, iPad and Apple TV.** Each frame is rendered just before the refresh it targets instead of two refreshes ahead. Apple TV moves onto this path from its video plane, so a controller press reaches the screen sooner.

### Android

- **A second screen becomes a companion panel.** On a dual-screen handheld or a foldable held like a laptop, the lower screen carries stats, the quick actions, a trackpad and the virtual controller while you stream.

### Hosts

- **PyroWave quality in bits per pixel.** Host → Settings carries a PyroWave quality row, 0.25 to 4 with 1.6 by default, that applies to every client and mode.
- **The scroll compositor hosts sessions,** as sway does.
- **HEVC 10-bit SDR on AMD and Intel Linux hosts encodes through Vulkan Video,** as AV1 and 8-bit sessions already did.
- **Installers store the GameStream choice where the console edits it.** The SteamOS and Omarchy installers, and an update of an older setup, write it through the new `punktfunk-host settings set`, so the console's toggle is no longer locked.

## Improved

- **PyroWave gets to the screen sooner.** A pinned stream is paced at the rate the bring-up measured instead of a fixed multiple, a frame starts leaving as its first packets are sealed, and NVIDIA encode queues on Linux run at high priority without the submit cost of realtime.
- **A/V sync counts the output device.** The speaker's own delay — the audio graph, the driver, a Bluetooth link — now enters the sync on every client, and synced audio holds its place instead of shedding and re-inserting a frame every few seconds.
- **Automatic reads the link better.** A desktop that goes still on a lossy link keeps its rate instead of sliding to the floor, the bring-up ramp reads a step at what the wire carried and ends on a declined step at once, and a late acknowledgement holds the controller instead of switching it off.
- **Scrolling glides on GNOME and wlroots hosts.** A trackpad arrives as a finger with its momentum instead of wheel clicks.
- **The host's frame-timing lock stays engaged.** When encode time swings with the scene, the lock no longer lets go and re-engages every half minute.
- **The first picture appears sooner on a Mac.** The stream's opening keyframe waits for the decoder instead of being dropped and asked for again.
- **Linux hosts spend less GPU on the pointer.** On KWin, wlroots and Hyprland the compositor draws the pointer into the frame, so the encoder skips a full-frame conversion pass a busy game was competing with.
- **Windows hosts raise the display driver's GPU priority,** so the encoder's colour conversion no longer queues behind a GPU-bound game.
- **Sharper colour edges.** Vulkan Video's direct path, NVIDIA's AV1 and the Windows HDR chroma pass all site chroma the way decoders expect, so fine colour detail stops shifting or turning grey.
- **Intel Linux clients decode through Vulkan Video,** and AV1 through VAAPI, where Intel's Vulkan AV1 output is wrong.
- **The console is lighter on a TV.** Its GPU programs compile before the first frame, screens share one cover cache and decode off the drawing thread, and the reduced interface renders its backdrop at a quarter of the pixels.
- **The stats overlay shows loss as a count** when few frames arrived, so one lost frame on a still Windows desktop no longer reads as a large share.
- **The docs site splits into Guide, Reference and Developers,** checked page by page against the current code. Every existing link still works.
- **Every package channel runs the same bun, 1.4.2.** Nix's older bun broke the plugin runner.

## Fixed

- **The pointer, on every host:** a Windows session keeps its pointer after a UAC prompt, a lock or a screensaver, follows a monitor you rearrange, and stays shown under touch or pen. - **Windows host audio:** two sessions share the loopback without reshaping each other's speakers, and only the last one out restores the defaults — even after the capture crashes. ## Security

- **A 100.64.0.0/10 peer counts as local only over Tailscale.** A neighbour behind the same carrier NAT no longer passes the console's local-network check or pairs as local. See *Before you update*.
- **Plugins stay inside their own sandbox.** The runner refuses binds that reach the host's processes, session bus, plugin tokens or the home's SSH keys, and reads manifests only from installed plugins. An id two packages claim is refused for both.
- **A plugin can no longer act for another.** Reporting another plugin's game as running, or hiding its source, is refused.
- **Official packages come only from the official source.** A third-party store source can no longer redirect Punktfunk's own plugins or the SDK refresh to its registry.
