Wire-compatible with 0.43.0: a new client streams from an old host and the other way round, so you can update one side at a time. On Windows the installer updates the host and its drivers together.

- **gamescope sessions on NVIDIA and Intel hosts show a picture again.** 0.43.0 streamed them green. It needs punktfunk-gamescope `+pfhdr31`.
- **Windows hosts keep every frame of a capped game.** The virtual display runs at twice the stream rate, so a frame that just misses the desktop's compose no longer stutters, and fixed-refresh clients get evenly spaced frames. The stream stays at its own rate.
- **Games that refuse injected input take it from Windows hosts,** including games behind kernel anti-cheat. Mouse and keyboard reach Windows as a USB-style device.
- **Android shows no green bar on the right edge** with HEVC from an AMD host at widths such as 2340.
- **The network check reports fast links at their speed.** Every link faster than about 77 Mbit/s read as 77.
- **Bazzite console updates finish** and restart the host. Since 0.41.0 they reported failure after installing. The update to 0.43.1 itself still needs a terminal; see Before you update.
- **Hydra opens in Big Picture** from its tile on Windows hosts and on Linux snap and AppImage installs, and every client shows Hydra's logo. It needs the Hydra plugin 0.2.0.
- **The Decky plugin finds the client on ARM devices** such as the Steam Frame.

## Before you update

- **Bazzite: update from a terminal this once.** A console update from 0.41.0 through 0.43.0 runs the old updater, which reports failure after the new version is in place and leaves the old host running. Run `sudo punktfunk-sysext update` instead. If the console already reported the failure, run it, then restart the box.
- **Windows: a game with V-Sync on renders at twice the stream rate** unless a frame limiter caps it, which costs GPU power. Cap it at the stream rate, or set `PUNKTFUNK_VDISPLAY_HZ_MULT=1` in host.env for the old display.
