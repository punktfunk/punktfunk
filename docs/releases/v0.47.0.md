Works with 0.46 apps and hosts, in either order. On Windows the installer updates the host and its drivers together. If you run the browser client, update its page to 0.4.0 or newer with your hosts. A few things need a step from you; see Before you update.

- **Punktfunk speaks German, Spanish, French, Italian and Brazilian Portuguese.** The apps, the console, the web console, the installers, the tray and the Steam Deck plugin follow your system's language.
- **Lock a profile.** It opens only on the devices you choose, or with its PIN, and a device can stay signed in with Face ID, a fingerprint or Windows Hello. A profile can also run on a family member's own Linux account, opened with their password.
- **Pick what each device's screen is:** the only screen, the main screen, a second screen beside your monitors, or one monitor. A preset can pick it, and **Play together** puts friends on one shared screen.
- **Stream settings per game.** Set a game's resolution, refresh rate, HDR and controller once in the web console; every app applies them when it starts the game.
- **Each profile has its own library:** hide a game for yourself, switch sources off, and on a desktop the box made, add games only you have.
- **The Android and Windows apps have a Library tab and a page for each host,** and every app has shortcuts you can change.
- **A lost packet heals faster.** A loss the app reports late heals in one frame on every encoder, and an AMD PC no longer resets its GPU after an AV1 loss.
- **The browser client is safe to reach from outside your home,** with Tailscale or a domain with a real certificate.

## Before you update

- **Pairing a browser that comes through the browser client's page.** Such a browser can no longer be approved with one click: browsers outside your network, and browsers on a network that blocks UDP. Under **Devices**, click **Arm PIN** on its row and type that PIN into the page. Browsers that are already paired keep working.
- **The first browser from a page at a public address** pairs the same way, unless that address is in **Browser origins**. Once one browser has paired from that page, the next ones are approved as usual.
- **Update the browser client's page to 0.4.0 or newer.** What changes on the page:
  - **A port forward to the default setup stops working from outside your network.** Use Tailscale (`compose.tailscale.yaml`), or give the page a domain with a real certificate: `DOMAIN=play.example.com docker compose -f compose.public.yaml up -d`.
  - **Behind your own reverse proxy, list your domain** in `TLS_NAMES`. The proxy must pass the `Host` header with its port and send `X-Forwarded-For`. In nginx: `proxy_set_header Host $http_host;` and `proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;`.
  - **A name other than `.local`, `.home.arpa` or `.internal`,** such as `nas.fritz.box`, must be in `TLS_NAMES`; the page names the one to add.
  - **Waking a host from the page needs a paired browser** that connected to it through the page in the last 30 days. Connect once while the host is awake.
  - **Reload any tab that was open across the update**, once.
- **A host you type in by address pairs by PIN.** Every app offers such a host the PIN only, and `punktfunk pair --request-access` needs the host's fingerprint, from `--fp` or a saved host. A host found on your network still offers **Request access**.
- **Apps from 0.43 or older no longer find a host on your network** on Linux, Windows and Android. A saved host or a typed address still connects.
- **Choosing a screen is a grant.** A device on **Full control** keeps it. A device with custom access needs **Choose its screen** ticked; without it, the device gets what the host decides.
- **Seats on someone's existing account run nothing the box chose:** no hooks, and on Windows only Verified plugins. On Linux the console manages no plugins or emulators there; the person installs their own plugins from their own console.
- **Linux plugins: a write outside `/tmp` waits for you.** A plugin that writes to a game library on another drive asks first; allow its folder request in the web console. A grant for `~/.local`, `~/.local/share`, `~/.var/app`, `~/snap` or a Windows `AppData` no longer binds: name the folder inside it.
- **Linux seats find your libraries under `/run/media/punktfunk`.** Restart a seat that is running, once.
- **Windows, an install folder outside Program Files:** the first upgrade renames files another account could have changed to `*.untrusted`. Delete them once the host runs.
- **`profiles.json` drops fields nothing read.** A passcode or device list set there never locked anything; use **Lock** on the profile's card.

## New

### Hosts

- **Lock a profile.** On the profile's card, **Lock** it to the devices you choose. A **PIN** of 4 to 8 digits lets another device in; wrong PINs slow down, up to a day. A device can keep a key and open the profile with it from then on. Moonlight can't type a PIN, so a Moonlight device opens a locked profile only from its list. See [Lock a profile](https://docs.punktfunk.unom.io/docs/profiles#lock-a-profile).
- **Linux: a profile on someone's own account.** **Add profile** → **Own desktop** → **Existing account**: the account and its password. Linux checks the password and keeps none. Repeated wrong passwords lock it for 15 minutes. The password also opens the person's KDE wallet. See [Own account](https://docs.punktfunk.unom.io/docs/own-account).
- **Screens.** Each device says what its screen is: the only screen, the main screen, a second screen beside your monitors, or one of your monitors. A Moonlight device can join a screen a Punktfunk app opened. See [Stream a monitor](https://docs.punktfunk.unom.io/docs/stream-a-monitor).
- **Play together** is a preset that puts friends on one shared screen, sized by the first device. See [Play together](https://docs.punktfunk.unom.io/docs/play-together).
- **Stream settings per game.** A game's **Launch** tab sets resolution, refresh rate, HDR and controller for every device that plays it; a source sets them for all its titles, and a shared set covers several games. Any resolution from 360 to 4320 lines and any rate from 24 to 240 Hz. The host only lowers what a device asks, never raises it. See [Game library](https://docs.punktfunk.unom.io/docs/game-library).
- **Each profile's own library.** A profile can hide games, switch sources off, and keep its own art, game settings and what a game's exit does. On a desktop the box made it can add games only it has. The web console's profile pick shows the library as that profile sees it.
- **A person's own console.** From inside their own desktop a person opens a web console of their own: **Punktfunk Settings** on Linux, **Open console** in the tray on Windows. There they install plugins and decide their folders, with no password. On Windows each seat runs its own plugins as its account.
- **Render scale above 1x no longer encodes pixels the app throws away.** The host scales the picture down first: in the display driver on Windows, on the GPU elsewhere.
- **Steam Frame on its wireless adapter.** Linux packages keep the adapter out of power save with Valve's low-latency settings, and a Frame prefers the host's address on that network.
- **AMD RX 9000 on Linux with VCN firmware older than 9.13.38:** a health check names the version and the fix, and colour conversion runs in the encoder instead of a shader that doubled encode time under load.

### Apps

- **Languages.** German, Spanish, French, Italian and Brazilian Portuguese in every app, the console, the web console, the Linux and Windows installers, the tray and the Steam Deck plugin. The host's own messages, checks and errors arrive in your language too. The console types Japanese, Chinese and Korean with your input method.
- **Locked profiles ask for their PIN** on iPhone, iPad, Mac, Apple TV, Vision Pro, Android, Windows, Linux and the console, on a number pad a controller reaches. A switch keeps the device signed in, behind Face ID, Touch ID, Optic ID, a fingerprint or Windows Hello where the device has one. The browser client and the webOS and Samsung TV apps can't open a locked profile yet.
- **Hide for me.** A title's menu hides it from your own profile's shelf; **Hidden for** brings it back.
- **Screen.** The host card's menu and a preset's **Host screen** row pick only, main or second screen, or a monitor. **New preset** offers a **Second screen** starter.
- **Shortcuts.** Settings → Input → Shortcuts binds a chord or a held button to any quick action, and records one from your pad. It replaces the read-only Stream controls list. Release input, mouse mode, fullscreen and minimize join the quick-actions dial.
- **Reset** at the end of General puts every setting back to a fresh install's, after asking. Hosts, pairings and presets stay.
- **Android: a page for each host, and the library is a tab.** A host's card says which machine it is, whether it answers and what a tap does; setup, power and removal sit on its page. The Library tab shows every paired host's desktop, recently played, favorites, launchers and games, with search and sort. **Add to home screen** moved to a game's Details sheet.
- **Windows app: Hosts and Library in a navigation pane.** Each host has a page whose fields save in place. The Library has a chip per host, search in the title bar, sort, and a details sheet for a title.
- **A waiting request shows a device code,** and the web console shows the same code beside the request.
- **DualSense speaker volume per pad,** on the pad's card in Controllers.
- **Steam Deck plugin.** It opens on what is happening: a pending update, the running stream, then one row per host. A host's menu offers its screen, Wake host and the host's power actions.
- **Command line.** `punktfunk screen`, `punktfunk actions` and `punktfunk device-code`.
- **webOS: Game picture mode** puts an LG TV in its game picture mode while you stream.

## Improved

### Hosts

- **Loss recovery.** Every encoder keeps the newest frame the app confirmed, so a loss reported late heals in one frame instead of a keyframe. A repair goes ahead of queued frames, a lost keyframe heals sooner, and a keyframe ask acts at once on Windows and on Linux PipeWire capture. PyroWave on a lossy link no longer shows blank patches.
- **Lower latency behind a busy GPU.** On NVENC and Vulkan hosts, a frame the encoder finishes is sent at once instead of when the next frame arrives: up to a frame sooner.
- **Smoother under load.** Capture and send threads on Linux keep their priority while a game saturates the CPU. Windows on ARM opens packets with hardware AES. Intel QSV hosts let a laptop or handheld idle.
- **Steam Deck plugin.** It reads the app's answers, not its English text, so it works in every language.

### Apps

- **Android chooses codecs by what its decoder can do.** An old Android TV no longer gets AV1 it can't decode.
- **Apple apps start their first stream sooner,** and a session no longer keeps a buffer pool per restart.
- **The Windows app's posters** arrive in batches instead of rebuilding the grid each time.
- **A refused launch** shows the host's reason at once, in every app and the console.
- **Apple: Allow VRR** shows on the Mac only; on iPhone, iPad and Vision Pro it did nothing.

  - After a major update refused the host's image, the host comes back on the next boot.
  - With Steam Game Recording on, the picture no longer freezes when a game starts.

  - On Nobara, **Return to Gaming Mode** no longer leaves the stream dark.
- **Shared screens.** A second device on a gamescope screen gets the picture, not only input. An HDR and an SDR device can share a screen. A resize by the first device keeps the second's mode.
- **Linux.**
  - A monitor switched off during a stream on Umbriel, niri or Hyprland comes back.
  - On Hyprland, the permission command the host prints grants screen capture and keeps your config valid.
  - A desktop of an odd width no longer streams sheared on NVIDIA or Intel.
  - An NVIDIA R620 driver no longer sends black frames to Android.
  - One failed check no longer turns HDR, 10-bit and 4:4:4 off until restart.
  - On KDE with Plasma Keyboard, as on Bazzite 45, typed capitals no longer arrive flipped, "Hello" as "hELLO". On Plasma 6.8 a character your layout lacks, such as an emoji, no longer vanishes.
- **Windows.**
  - A resize right after connecting no longer gives 15 seconds of black.
  - Touch and pen land where you touch when a monitor sits left of or above the main one.
  - A key no longer stays held after a stream.
  - A TV-only box keeps its sound on the TV.
  - Punktfunk's speakers carry their own name, so SteamVR no longer takes them for its streaming speakers.

  - Linux seats see the owner's Steam libraries with Steam's container client, on ZFS, on Flatpak, Snap and Debian layouts, and through a `steamapps` link. They install on the library's own drive.
  - Two seats' PlayStation pads no longer leave a pad without a driver, and a seat's Steam no longer fights the owner's for the pad.
  - A Windows seat on an existing account keeps its session across a service restart, and a changed password no longer locks the account out.

- **Steam Deck plugin.** Launches no longer start inside Proton and drop back to Play, and **Force stop** works on a native install. A Steam Controller on a docked Deck no longer sends Steam's desktop keys and mouse to the host on top of the pad.

### Apps

- **Apple.**
  - Memory stays flat in long sessions. The apps kept decoded pictures they no longer drew, up to 2.4 GB at 4K.
  - After the display re-links, a stream no longer presents two frames in three for the rest of the session, worst on Apple TV with HDR.
  - A lost HEVC frame no longer freezes the picture for half a second.

## Security

- **The browser client's page** can no longer be used to pair as if from home, reaches nothing on your network but Punktfunk hosts, and a pairing request shows the page it came from.
- **Pairing.** Someone trying PINs from outside can no longer block pairing at home, and two ceremonies can no longer pass on one PIN.
- **A paired guest** needs **Choose its screen** to pick which screen it watches.
- **Plugins.** A plugin can no longer run code outside its sandbox through a write, a link, a start-up file or an emulator's flags. Each plugin's page runs on its own origin, so one plugin can't read another's settings.
- **Seats.** A seat can no longer swap a shared folder with a link, forge a controller or take another seat's pad. On Windows, Remote Desktop stays on this PC when you chose that.
- **Network.** A peer can no longer park memory on the host before it is admitted, hold connection slots by staying silent, or flood the Moonlight control port.
- **Apple.** A redial after a lost trust prompt no longer streams as trusted, the device key no longer goes into backups, and a malformed stream can no longer crash the app or ask the GPU for gigabytes.
- **Android.** A PIN's last digit no longer shows on the TV.
- **Linux app.** A host or game name can no longer put a link in a notification, and the Omarchy menu quotes a saved host's address.
- **Windows.** The installer locks an install folder before it trusts what is in it.
