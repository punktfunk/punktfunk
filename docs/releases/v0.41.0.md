Wire-compatible with 0.40.0: a new client streams from an old host and the other way round, so you can update one side at a time. End game, keys that never stick and presets the host can see need 0.41 on both sides. On Windows the installer updates the host and its drivers together.

- **Apple Vision Pro.** The iPhone and iPad app runs on Vision Pro, with several streams at once and a theater that lights the room.
- **End game from any client.** A game this device launched ends from the library, the console or the quick-action ring, and the stream closes once it is gone.
- **KDE hosts keep every frame.** Under a game's GPU load the stream carries the frames the game renders, 120 Hz holds 120 fps, and a mid-stream resolution change takes.
- **AMD Windows hosts stop stuttering under load.** The encoder reads the finished desktop directly instead of copying it on the GPU the game uses.
- **Keys stop sticking.** Presses and releases travel on the reliable channel, so a lost packet no longer holds a key down.
- **Large libraries load.** Every client fetches the library a page at a time, and the web console gives each game its own page, with art from the sources you pick.
- **Settings get simpler.** Rows most players never change sit under Show advanced, names match on every client, and any resolution can be typed.
- **Steam Deck hosts follow releases.** A new SteamOS install tracks the stable channel instead of canary.

## Before you update

- **A Steam Deck host installed earlier stays on canary.** To follow releases, run `git -C ~/punktfunk fetch && git -C ~/punktfunk switch stable`, then `bash ~/punktfunk/scripts/steamdeck/update.sh --pull`.
- **Host switches typed by hand now read the way the console shows them.** `false`, `off` and `no` turn every switch off, and `auto` no longer counts as on. Check `host.env` for a switch that relied on the old reading.
- **Browser sessions report as `web`.** An automation hook filtered on the native plane no longer fires for them: add a `web` hook or drop the filter. Plugins built on SDK 0.3.2 or older see browser events as unknown.
- **Browser streaming behind ufw or firewalld:** an update keeps an older rule that lacks UDP 9778. The package prints the command that refreshes it.
- **Advanced settings are hidden, not reset.** Codec, chroma, compositor, decoder and similar rows sit under Show advanced. The console's Start in collections and the Mac's Safe windowed presentation are gone.
- **Mac: with Capture system shortcuts on, ⌃⌘F goes to the host.** Press ⌘⎋ to release capture, then use the Stream menu to toggle fullscreen.
- **Linux hosts: Steam may list a virtual DualSense Edge as a new controller once,** because its serial changed.

## Improved

- **AMD Windows hosts** read the finished desktop picture directly, so a busy game no longer stutters the stream, and the desktop no longer drops to 10 fps after a session.
- **NVIDIA Windows hosts** remember the split-frame mode they measured as fastest and reopen at it after an encoder rebuild.
- **Covers load.** The host's management API speaks HTTP/2, so a screen full of covers shares one connection, and paging a large library reuses the list the host built.
- **Host settings and pairings are saved atomically.** A power cut leaves the old file or the new one, never an empty one.
- **Desktop clients present with less work.** A picture that fits the window is drawn straight into it, a busy present waits on the GPU instead of spinning, and AMD on Windows presents without stalls.
- **Linux clients:** VAAPI decode no longer blocks the pipeline, and Intel's media engine stays clocked up on the i915 driver, so 4K HEVC decodes in less than half the time.
- **Desktop clients stop asking the host for the phase lock,** which saves 3–4 ms end to end on an integrated GPU at 4K. Video threads run at raised priority.
- **The stats show where the time goes.** Decode is timed on every frame, latch splits into the client's GPU time and the compositor's floor, and a stats line reaches the log every second.
- **Android:** pad sticks, triggers and captured mouse-look arrive up to a frame sooner. Starting the mic and closing a session no longer stall the screen. Discovery pauses in the background, audio threads run at audio priority, older decoders show a frame when it lands, and PyroWave in landscape keeps its swapchain.
- **Apple:** the mic reaches the host up to 100 ms sooner, a pasted host item starts at once, posters decode off the main thread, and an unreachable host fails at once instead of after 15 s. PyroWave on the Mac shows every frame instead of about two in three, and every Mac window presents through the faster path.
- **Web console:** the activity feed shows every event and names the game, plugin pages follow the console's theme, the hook form searches the library as you type, and allowing a folder grants it directly, with write access if you add it.
- **The Windows client's settings page** no longer rescans GPUs and audio devices on every click.

On KWin 6.6 and 6.7 a 120 Hz stream holds 120 fps instead of 111–114, and on 6.7 a resolution change mid-stream changes the stream. Browser video no longer judders.

## Security

- **A client that stalls the pairing exchange can't try the same PIN again** in a later attempt.
- **A new identity at a saved address asks for a PIN.** The Windows client trusted it silently, Android's trust prompt now pins the fingerprint the host advertises, and a link whose fingerprint has non-ASCII digits is refused.
- **Apple clients never talk to an unpaired host** for the console shelf, the running-game check or launch art, and a muted mic stays closed across an audio engine restart.
- **`punktfunk-host ctl` opens the console at 127.0.0.1,** so another local account can't catch the sign-in ticket.
- **Windows hosts load the NVIDIA library by full path, and System32 tools never resolve through PATH.**
- **The Linux installer** creates its sudo helper folder fresh and private, and writes host settings owner-only.
- **An update's anti-rollback floor rises** even when its state file can't be renamed.
- **Plugins can't reorder what a prompt shows** with bidi marks, a planted token link is replaced, and sandbox binds at or above punktfunk's config folder are refused.
- **The web console** refuses a sign-in redirect off the site, never picks a Moonlight device for you, and asks for your password on every launch kind the host treats as privileged. An idle browser can't hold a session slot during sign-in.
