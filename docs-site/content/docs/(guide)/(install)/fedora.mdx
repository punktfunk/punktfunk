Install the host on **Fedora 43 or 44**, Workstation or KDE. Bazzite and other Fedora Atomic spins
have [their own page](/docs/bazzite).

**One command instead?** The [guided installer](/docs/install#guided-install-preview) (preview)
does steps 2 to 4 and warns when step 1 is missing:

<Installer />

## 1. GPU driver

- **NVIDIA:** the driver comes from **RPM Fusion**. Enable it, install, reboot:

  ```sh
  sudo dnf install \
    https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm \
    https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm
  sudo dnf install akmod-nvidia xorg-x11-drv-nvidia-cuda
  ```

  With Secure Boot on, the module won't load until you enrol its key:
  [Troubleshooting](/docs/troubleshooting#nvidia-smi-says-it-cant-communicate-with-the-driver).
- **AMD / Intel:** nothing to install; Mesa carries Vulkan Video and VAAPI. For every codec, add RPM
  Fusion's `mesa-va-drivers-freeworld` (AMD) or `intel-media-driver` (Intel).

## 2. Install the host

Add the repo and install the host, the console and the plugin runner. On **Fedora 43**, change
`fedora-44` to `bazzite` in `baseurl` first (`rpm -E %fedora` prints your release):

<Install platform="fedora" />

`sudo dnf upgrade` updates it from then on. Restart the host afterwards with
`systemctl --user restart punktfunk-host`, or let the [console update it](/docs/updating).

## 3. Let it use your controllers

Join the groups, then **log out and back in**:

```sh
sudo usermod -aG input "$USER"       # virtual gamepads
sudo usermod -aG punktfunk "$USER"   # virtual Steam Deck controller
```

## 4. Start it

From a terminal inside your desktop session:

```sh
systemctl --user enable --now punktfunk-host punktfunk-web
```

Fedora runs **firewalld**, and no client reaches the host until you open it. Open the host, and the
console for other devices:

```sh
sudo firewall-cmd --reload   # load the service definitions the package installed
sudo firewall-cmd --permanent --add-service=punktfunk-native --add-service=punktfunk-web
sudo firewall-cmd --reload
```

For [Moonlight](/docs/moonlight), also add `punktfunk-gamestream` ([Ports & firewall](/docs/ports)).
